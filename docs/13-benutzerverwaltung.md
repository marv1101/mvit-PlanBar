# Benutzerverwaltung

Die Benutzerverwaltung ermöglicht Administratoren, alle Benutzer des Systems zu verwalten.

## Benutzerliste

Die Liste zeigt alle registrierten Benutzer:

| Spalte | Beschreibung |
|--------|-------------|
| Name | Vollständiger Name |
| E-Mail | Kontakt-E-Mail |
| Rolle | Zugewiesene Benutzerrolle |
| Status | Aktiv / Inaktiv |
| Letzter Login | Zeitpunkt des letzten Logins |

## Neuen Benutzer erstellen

1. Klicken Sie auf **„Neuen Benutzer erstellen"**
2. Füllen Sie die Felder aus:

### Pflichtfelder

| Feld | Beschreibung |
|------|-------------|
| Vorname | Erster Name |
| Nachname | Familienname |
| E-Mail | Login-E-Mail-Adresse |
| Rolle | Benutzerrolle (Admin, Mitarbeiter) |

### Optionale Felder

| Feld | Beschreibung |
|------|-------------|
| Passwort | Initiales Passwort (wird generiert, wenn leer) |
| Status | Aktiv / Inaktiv |

3. Klicken Sie auf **„Erstellen"**

> **Hinweis:** Der neue Benutzer erhält automatisch eine Einladungs-E-Mail mit seinen Zugangsdaten.

## Benutzerrollen

| Rolle | Berechtigungen |
|-------|---------------|
| **Administrator** | Voller Zugriff auf alle Funktionen |
| **Schichtleiter** | Dienstpläne erstellen, Wünsche genehmigen |
| **Mitarbeiter** | Eigene Daten anzeigen, Wünsche einreichen |

### Rolle ändern

1. Öffnen Sie die Benutzerdetails
2. Ändern Sie die **Rolle**
3. Speichern Sie die Änderung

> **Warnung:** Die Änderung der Benutzerrolle tritt sofort in Kraft!

## Benutzer bearbeiten

1. Klicken Sie auf den Benutzernamen in der Liste
2. Ändern Sie die gewünschten Felder
3. Klicken Sie auf **„Speichern"**

## Benutzer deaktivieren

1. Öffnen Sie die Benutzerdetails
2. Setzen Sie den Status auf **„Inaktiv"**
3. Speichern Sie die Änderung

> **Hinweis:** Deaktivierte Benutzer können sich nicht mehr anmelden, aber ihre Daten bleiben erhalten.

## Benutzer löschen

1. Klicken Sie auf das **Lösch-Symbol** (🗑️) neben dem Benutzer
2. Bestätigen Sie die Löschung

> **Warnung:** Das Löschen eines Benutzers ist endgültig! Alle zugehörigen Daten werden ebenfalls gelöscht.

## Passwort zurücksetzen

1. Öffnen Sie die Benutzerdetails
2. Klicken Sie auf **„Passwort zurücksetzen"**
3. Der Benutzer erhält eine E-Mail mit einem Link zum Zurücksetzen

## Bulk-Aktionen

Für die Verwaltung mehrerer Benutzer gleichzeitig:

1. Wählen Sie mehrere Benutzer per Häkchen aus
2. Verwenden Sie die Aktionen in der Kopfzeile:
   - **Alle auswählen/abwählen**
   - **Status ändern**
   - **Rolle zuweisen**
   - **Löschen**

## Import/Export

### Benutzer importieren

1. Klicken Sie auf **„Importieren"**
2. Laden Sie eine CSV-Datei hoch
3. Überprüfen Sie die Vorschau
4. Bestätigen Sie den Import

### Benutzer exportieren

1. Klicken Sie auf **„Exportieren"**
2. Wählen Sie das Format (CSV, Excel)
3. Die Datei wird automatisch heruntergeladen
