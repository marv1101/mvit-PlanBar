## Über PlanBar

PlanBar ist eine webbasierte Schichtplanungsanwendung für KMU in Deutschland. Das System besteht aus drei Komponenten:

- **Frontend** – React-SPA mit Drag-and-Drop-Kalender
- **Backend** – FastAPI-REST-API für Geschäftslogik
- **TiTO** – Automatischer Schichtplan-Optimierer

### Zielgruppe

- **Schichtleiter** – Erstellen und optimieren Dienstpläne
- **Mitarbeiter** – Tragen Schichtwünsche ein und sehen Ihren Dienstplan
- **Administratoren** – Verwalten Benutzer, Rollen und Systemeinstellungen

### Voraussetzungen

- Moderner Webbrowser (Chrome, Firefox, Edge, Safari)
- Internetverbindung
- Für Mobile: Responsive Design unterstützt Smartphones und Tablets
