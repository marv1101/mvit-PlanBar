# Dienstplan erstellen (Manuell)

Der manuelle Dienstplan-Modus ermöglicht Ihnen, Schichten per Drag-and-Drop direkt im Kalender zuzuweisen.

## Neue Dienstplan erstellen

1. Navigieren Sie zu **„Dienstplan"**
2. Klicken Sie auf **„Neuen Dienstplan erstellen"**
3. Geben Sie die Grunddaten ein:

### Grunddaten

| Feld | Beschreibung |
|------|-------------|
| Name | Bezeichnung (z.B. „Dezember 2026") |
| Zeitraum | Start- und Enddatum |
| Beschreibung | Zusätzliche Informationen |

4. Klicken Sie auf **„Erstellen"**

## Schichten zuweisen

### Drag-and-Drop

1. Wählen Sie einen **Mitarbeiter** aus der linken Leiste
2. Ziehen Sie den Namen auf den gewünschten **Tag** im Kalender
3. Wählen Sie die **Rolle** (Früh-/Spät-/Nachtschicht)
4. Die Schicht wird zugewiesen

### Mehrere Schichten gleichzeitig

1. Halten Sie die **Strg-Taste** (Windows) bzw. **⌘-Taste** (Mac) gedrückt
2. Ziehen Sie Mitarbeiter auf mehrere Tage
3. Alle ausgewählten Tage erhalten die gleiche Schicht

### Schicht entfernen

1. Klicken Sie auf die zugewiesene Schicht im Kalender
2. Klicken Sie auf **„Entfernen"** oder drücken Sie die **Entf-Taste**

Zeigt eine Woche mit allen Tagen und Schichten.

Zeigt den gesamten Monat im Überblick.

## Status des Dienstplans

| Status | Beschreibung |
|--------|-------------|
| 📝 **Entwurf** | Plan kann bearbeitet werden |
| 📤 **Eingereicht** | Plan wurde an TiTO übermittelt |
| ✅ **Abgeschlossen** | Optimierung erfolgreich |
| ❌ **Fehlgeschlagen** | Optimierung fehlgeschlagen |

## Plan speichern

1. Klicken Sie auf **„Speichern"** (oben rechts)
2. Der Plan bleibt im Status **„Entwurf"**

> **Hinweis:** Vergessen Sie nicht regelmäßig zu speichern!

## Plan an TiTO übermitteln

1. Stellen Sie sicher, dass der Plan im Status **„Entwurf"** ist
2. Klicken Sie auf **„An TiTO übermitteln"**
3. Der Plan wird automatisch optimiert
4. Warten Sie auf das Ergebnis (Dauer hängt von der Komplexität ab)

## Plan wiederholen

Wenn ein Plan fehlgeschlagen ist oder Sie eine neue Version erstellen möchten:

1. Klicken Sie auf **„Plan wiederholen"**
2. Der Plan wird zurückgesetzt
3. Nehmen Sie Ihre Änderungen vor
4. Übermitteln Sie den Plan erneut
