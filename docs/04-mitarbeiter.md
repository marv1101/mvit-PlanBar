# Mitarbeiter verwalten

Die Mitarbeiterverwaltung ist der zentrale Bereich für die Verwaltung Ihres Personals.

## Mitarbeiterliste

Die Liste zeigt alle registrierten Mitarbeiter mit:

| Spalte | Beschreibung |
|--------|-------------|
| Name | Vor- und Nachname |
| E-Mail | Kontakt-E-Mail |
| Rolle | Zugewiesene Schichtrolle |
| Status | Aktiv / Inaktiv |
| Farbe | Individuelle Farbe im Kalender |

### Aktionen

| Aktion | Beschreibung |
|--------|-------------|
| ➕ Neu | Neuen Mitarbeiter hinzufügen |
| ✏️ Bearbeiten | Mitarbeiterdaten ändern |
| 🗑️ Löschen | Mitarbeiter entfernen |
| 👁️ Details | Ausführliche Informationen anzeigen |

## Neuen Mitarbeiter hinzufügen

1. Klicken Sie auf **„Mitarbeiter hinzufügen"** (oben rechts)
2. Füllen Sie die Pflichtfelder aus:

### Pflichtfelder

| Feld | Beschreibung | Beispiel |
|------|-------------|----------|
| Vorname | Erster Name | Max |
| Nachname | Familienname | Müller |
| E-Mail | Kontakt-Adresse | max@firma.de |
| Rolle | Schichtrolle | Frühschicht |

### Optionale Felder

| Feld | Beschreibung |
|------|-------------|
| Telefon | Telefonnummer |
| Farbe | Individuelle Farbe für den Kalender |
| Arbeitszeit (Woche) | Stunden pro Woche |
| Aktiv | Ja/Nein – Ist Mitarbeiter aktiv? |

3. Klicken Sie auf **„Speichern"**

> **Hinweis:** Neue Mitarbeiter erhalten automatisch eine Einladungs-E-Mail mit ihren Zugangsdaten.

## Mitarbeiter bearbeiten

1. Klicken Sie in der Mitarbeiterliste auf den Namen oder das **Bearbeiten-Symbol** (✏️)
2. Ändern Sie die gewünschten Felder
3. Klicken Sie auf **„Speichern"**

## Mitarbeiter löschen

1. Klicken Sie auf das **Lösch-Symbol** (🗑️) neben dem Mitarbeiter
2. Bestätigen Sie die Löschung

> **Warnung:** Das Löschen eines Mitarbeiters ist endgültig! Alle zugehörigen Daten (Schichtwünsche, Zuweisungen) werden ebenfalls gelöscht.

## Status verwalten

| Status | Bedeutung |
|--------|-----------|
| **Aktiv** | Mitarbeiter ist im System und kann Schichten zugewiesen bekommen |
| **Inaktiv** | Mitarbeiter ist temporär deaktiviert (z.B. Elternzeit) |

### Status ändern

1. Öffnen Sie die Mitarbeiterdetails
2. Wechseln Sie den Status über den Schalter
3. Speichern Sie die Änderung

## Bulk-Aktionen

Für die Verwaltung mehrerer Mitarbeiter gleichzeitig:

1. Wählen Sie mehrere Mitarbeiter per Häkchen aus
2. Verwenden Sie die Aktionen in der Kopfzeile:
   - **Alle auswählen/abwählen**
   - **Status ändern**
   - **Rolle zuweisen**

## Import/Export

### Mitarbeiter importieren

1. Klicken Sie auf **„Importieren"**
2. Laden Sie eine CSV-Datei hoch (Format: Name, E-Mail, Rolle)
3. Überprüfen Sie die Vorschau
4. Bestätigen Sie den Import

### Mitarbeiter exportieren

1. Klicken Sie auf **„Exportieren"**
2. Wählen Sie das Format (CSV, Excel)
3. Die Datei wird automatisch heruntergeladen
