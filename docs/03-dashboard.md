# Dashboard – Die Übersicht

Das Dashboard ist Ihre zentrale Anlaufstelle. Hier sehen Sie auf einen Blick:

## Dashboard-Bereiche

### 1. Mitarbeiter heute
Zeigt alle Mitarbeiter, die heute Schicht haben.

```
┌─────────────────────────────────────┐
│  👥 Mitarbeiter heute (5)           │
│                                     │
│  🔵 Max Müller    – Frühschicht    │
│  🟢 Anna Schmidt  – Spätschicht    │
│  🟡 Peter Weber   – Nachtschicht   │
│  🔵 Lisa Braun    – Frühschicht    │
│  🟢 Tom Klein     – Spätschicht    │
└─────────────────────────────────────┘
```

### 2. Aktiver Dienstplan
Zeigt den aktuellen Dienstplan mit Status:

| Status | Bedeutung |
|--------|-----------|
| 📝 Entwurf | Plan wird erstellt |
| 📤 Eingereicht | Plan an TiTO übermittelt |
| ✅ Abgeschlossen | Plan ist fertig optimiert |
| ❌ Fehlgeschlagen | Optimierung fehlgeschlagen (Wiederholung möglich) |

### 3. Offene Anfragen
Zeigt Schichtwünsche, die noch bearbeitet werden müssen:

- **Urlaubsanträge** – Mitarbeiter möchte Urlaub
- **Bevorzugte Schichten** – Mitarbeiter bevorzugt bestimmte Zeiten
- **Nicht-verfügbare Zeiten** – Mitarbeiter kann bestimmte Zeiten nicht

### 4. Statistiken
Kurzübersicht über:

- Gesamtzahl Mitarbeiter
- Anzahl definierter Rollen
- Offene Schichtwünsche
- Aktive Dienstpläne

## Navigation

Über die linke Seitenleiste gelangen Sie zu allen Bereich:

| Bereich | Beschreibung |
|---------|-------------|
| 📊 Dashboard | Diese Übersicht |
| 👥 Mitarbeiter | Mitarbeiter verwalten |
| 🎭 Rollen | Schichtrollen definieren |
| 📋 Dienstplan | Dienstpläne erstellen/bearbeiten |
| 📌 Pinboard | Ankündigungen und Notizen |
| ⏱️ Zeitkonto | Arbeitszeiten einsehen |
| 👤 Mein Profil | Persönliche Einstellungen |

> **Tipp:** Auf Mobilgeräten können Sie die Navigation über das汉堡-Menü (☰) oben links öffnen.
