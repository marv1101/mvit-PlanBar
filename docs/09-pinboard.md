# Pinboard – Ankündigungen

Das Pinboard dient der internen Kommunikation. Hier können Sie Ankündigungen, Notizen und Informationen mit dem Team teilen.

## Pinboard öffnen

1. Navigieren Sie zu **„Pinboard"** in der Seitenleiste
2. Sie sehen alle vorhandenen Einträge

## Neuen Eintrag erstellen

1. Klicken Sie auf **„Neuer Eintrag"**
2. Füllen Sie die Felder aus:

### Pflichtfelder

| Feld | Beschreibung |
|------|-------------|
| Titel | Überschrift des Eintrags |
| Inhalt | Text des Eintrags |

### Optionale Felder

| Feld | Beschreibung |
|------|-------------|
| Kategorie | Einordnung (z.B. „Wichtig", „Info", „Feiertage") |
| Priorität | Hoch / Mittel / Niedrig |
| Anhänge | Dateien hochladen (Bilder, PDFs) |
| Sichtbarkeit | Alle / Nur bestimmte Rollen |

3. Klicken Sie auf **„Veröffentlichen"**

## Einträge verwalten

### Eintrag bearbeiten

1. Klicken Sie auf den Eintrag
2. Klicken Sie auf **„Bearbeiten"**
3. Nehmen Sie Ihre Änderungen vor
4. Speichern Sie die Änderung

### Eintrag löschen

1. Klicken Sie auf den Eintrag
2. Klicken Sie auf **„Löschen"**
3. Bestätigen Sie die Löschung

## Kategorien

| Kategorie | Beschreibung |
|-----------|-------------|
| 📢 Wichtig | Dringende Ankündigungen |
| ℹ️ Info | Allgemeine Informationen |
| 🎄 Feiertage | Feiertage und besondere Termine |
| 🔧 Wartung | Systemwartungen |
| 📋 Sonstiges | Alles andere |

## Prioritäten

| Priorität | Anzeige |
|-----------|---------|
| 🔴 Hoch | Rot markiert, oben in der Liste |
| 🟡 Mittel | Gelb markiert |
| 🟢 Niedrig | Normal angezeigt |

## Anhänge

Sie können Dateien an Einträge anhängen:

1. Erstellen oder bearbeiten Sie einen Eintrag
2. Klicken Sie auf **„Datei anhängen"**
3. Wählen Sie die Datei aus
4. Die Datei wird hochgeladen und angezeigt

> **Hinweis:** Erlaubte Dateitypen: Bilder (JPG, PNG, GIF), PDFs, Dokumente. Maximale Dateigröße: 10 MB.

## Benachrichtigungen

Wenn ein neuer Eintrag erstellt oder ein bestehender Eintrag aktualisiert wird, erhalten alle Benutzer eine Benachrichtigung im System.

## Pinboard als Dashboard-Widget

Das Pinboard kann auch als Widget auf dem Dashboard angezeigt werden:

1. Navigieren Sie zu **„Dashboard"**
2. Das **„Pinboard"-Widget** zeigt die neuesten Einträge
3. Klicken Sie auf einen Eintrag, um den vollständigen Text zu lesen
