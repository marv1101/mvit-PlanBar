# Schichtwünsche einreichen

Mitarbeiter können Schichtwünsche einreichen, um ihre Verfügbarkeit und Präferenzen mitzuteilen.

## Arten von Schichtwünschen

| Typ | Beschreibung | Beispiel |
|-----|-------------|----------|
| **Urlaub** | Zeitraum komplett nicht verfügbar | 24.12. – 02.01. |
| **Bevorzugt** | Bevorzugte Schichten oder Zeiten | Lieber Spätschicht |
| **Nicht verfügbar** | Bestimmte Tage/Zeiten nicht möglich | Montagmorgen nicht |

## Neuen Schichtwunsch einreichen

### Als Mitarbeiter (Self-Service)

1. Navigieren Sie zu **„Mein Profil"** → **„Meine Wünsche"**
2. Klicken Sie auf **„Neuen Wunsch einreichen"**
3. Wählen Sie den **Typ** aus:
   - 🏖️ Urlaub
   - ⭐ Bevorzugt
   - 🚫 Nicht verfügbar
4. Geben Sie den **Zeitraum** ein:
   - **Startdatum**
   - **Enddatum** (optional – für ganztägige Wünsche)
5. Fügen Sie eine **Beschreibung** hinzu (optional)
6. Klicken Sie auf **„Einreichen"**

### Als Schichtleiter/Admin

1. Navigieren Sie zu **„Schichtwünsche"**
2. Klicken Sie auf **„Neuen Wunsch erstellen"**
3. Wählen Sie den **Mitarbeiter** aus
4. Wählen Sie den **Typ** und den **Zeitraum**
5. Speichern Sie den Wunsch

## Wünsche bearbeiten

1. Öffnen Sie die Wunschliste
2. Klicken Sie auf den zu bearbeitenden Wunsch
3. Ändern Sie die gewünschten Felder
4. Speichern Sie die Änderung

> **Hinweis:** Einreichte Wünsche können nur bearbeitet werden, solange sie noch nicht in einem aktiven Dienstplan verarbeitet wurden.

## Wünsche genehmigen/ablehnen (Admin)

1. Navigieren Sie zu **„Schichtwünsche"**
2. Sie sehen alle offenen Wünsche
3. Klicken Sie für einen Wunsch auf:
   - ✅ **Genehmigen** – Wunsch wird berücksichtigt
   - ❌ **Ablehnen** – Wunsch wird abgelehnt (Grund eingeben)

> **Hinweis:** Genehmigte Wünsche werden vom TiTO-Optimierer automatisch bei der Schichtplanung berücksichtigt.

## Kalenderansicht

In der Kalenderansicht sehen Sie alle Wünsche farblich markiert:

| Farbe | Bedeutung |
|-------|-----------|
| 🟢 Grün | Genehmigt |
| 🟡 Gelb | Ausstehend |
| 🔴 Rot | Abgelehnt |
| 🔵 Blau | In Bearbeitung |

## Wünsche löschen

1. Wählen Sie den Wunsch aus
2. Klicken Sie auf **„Löschen"**
3. Bestätigen Sie die Löschung

> **Hinweis:** Gelöschte Wünsche können nicht wiederhergestellt werden.
