# Profil und Einstellungen

Verwalten Sie Ihr persönliches Profil und Ihre Einstellungen.

## Mein Profil

1. Klicken Sie auf Ihr **Profilbild** (oben rechts)
2. Wählen Sie **„Mein Profil"**

### Profilinformationen

| Feld | Beschreibung |
|------|-------------|
| Name | Ihr vollständiger Name |
| E-Mail | Ihre E-Mail-Adresse |
| Rolle | Ihre Schichtrolle |
| Status | Aktiv / Inaktiv |

### Profilbild ändern

1. Klicken Sie auf Ihr aktuelles Profilbild
2. Wählen Sie ein neues Bild aus
3. Die Änderung wird automatisch gespeichert

## Passwort ändern

1. Öffnen Sie **„Mein Profil"**
2. Klicken Sie auf **„Passwort ändern"**
3. Füllen Sie die Felder aus:

| Feld | Beschreibung |
|------|-------------|
| Aktuelles Passwort | Ihr derzeitiges Passwort |
| Neues Passwort | Ihr neues Passwort |
| Neues Passwort bestätigen | Neues Passwort erneut eingeben |

4. Klicken Sie auf **„Speichern"**

> **Sicherheitshinweis:** Wählen Sie ein sicheres Passwort mit mind. 8 Zeichen, Groß-/Kleinbuchstaben, Zahlen und Sonderzeichen.

## Einstellungen

### Dark Mode

1. Öffnen Sie **„Einstellungen"**
2. Aktivieren oder deaktivieren Sie **„Dunkler Modus"**

### Sprache

1. Öffnen Sie **„Einstellungen"**
2. Wählen Sie Ihre bevorzugte **Sprache** aus:
   - 🇩🇪 Deutsch
   - 🇬🇧 Englisch

### Benachrichtigungen

1. Öffnen Sie **„Einstellungen"**
2. Konfigurieren Sie Ihre **Benachrichtigungen**:

| Option | Beschreibung |
|--------|-------------|
| E-Mail-Benachrichtigungen | Erhalten Sie Updates per E-Mail |
| Pinboard-Erinnerungen | Benachrichtigung bei neuen Pinboard-Einträgen |
| Schichtänderungen | Benachrichtigung bei Änderungen am Dienstplan |

## Meine Wünsche

1. Öffnen Sie **„Mein Profil"**
2. Klicken Sie auf **„Meine Wünsche"**
3. Sie sehen alle Ihre eingetragenen Schichtwünsche

### Neuen Wunsch einreichen

1. Klicken Sie auf **„Neuen Wunsch"**
2. Wählen Sie den **Typ** (Urlaub/Bevorzugt/Nicht verfügbar)
3. Geben Sie den **Zeitraum** ein
4. Speichern Sie den Wunsch

### Wunsch bearbeiten/löschen

1. Klicken Sie auf den Wunsch
2. Bearbeiten oder löschen Sie den Wunsch

## Abmelden

1. Klicken Sie auf Ihr **Profilbild**
2. Wählen Sie **„Abmelden"**

> **Sicherheitshinweis:** Melden Sie sich immer ab, wenn Sie PlanBar auf einem gemeinsam genutzten Gerät verwenden.
