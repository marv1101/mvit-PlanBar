# Tastenkürzel

PlanBar unterstützt Tastenkürzel für eine schnellere Navigation und Bedienung.

## Allgemeine Tastenkürzel

| Taste | Aktion |
|-------|--------|
| `Strg + S` | Aktuelle Ansicht speichern |
| `Strg + Z` | Letzte Aktion rückgängig |
| `Strg + Y` | Letzte Aktion wiederherstellen |
| `Esc` | Dialog schließen / Abbrechen |
| `F5` | Seite aktualisieren |
| `Strg + F` | Suche öffnen |

## Navigation

| Taste | Aktion |
|-------|--------|
| `Alt + D` | Dashboard öffnen |
| `Alt + M` | Mitarbeiter öffnen |
| `Alt + R` | Rollen öffnen |
| `Alt + P` | Dienstplan öffnen |
| `Alt + B` | Pinboard öffnen |
| `Alt + Z` | Zeitkonto öffnen |
| `Alt + U` | Mein Profil öffnen |

## Mitarbeiterverwaltung

| Taste | Aktion |
|-------|--------|
| `N` | Neuen Mitarbeiter erstellen |
| `E` | Ausgewählten Mitarbeiter bearbeiten |
| `Entf` | Ausgewählten Mitarbeiter löschen |
| `Strg + A` | Alle Mitarbeiter auswählen |

## Dienstplan

| Taste | Aktion |
|-------|--------|
| `N` | Neuen Dienstplan erstellen |
| `S` | Aktuellen Plan speichern |
| `Strg + Enter` | Plan an TiTO übermitteln |
| `Strg + Entf` | Ausgewählte Schicht entfernen |
| `←` | Vorheriger Tag/Woche/Monat |
| `→` | Nächster Tag/Woche/Monat |
| `T` | Zum heutigen Datum springen |

## Pinboard

| Taste | Aktion |
|-------|--------|
| `N` | Neuen Eintrag erstellen |
| `E` | Ausgewählten Eintrag bearbeiten |
| `Entf` | Ausgewählten Eintrag löschen |

## Tipp

Die Tastenkürzel funktionieren nur, wenn keine Eingabefelder aktiv sind. Klicken Sie zunächst in einen freien Bereich der Seite.
