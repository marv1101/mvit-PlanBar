# Architecture Decision Records (ADR)

Dieses Verzeichnis enthält Architecture Decision Records (ADRs) für PlanBar.
Jeder ADR dokumentiert eine signifikante architektonische, organisatorische oder
produktbezogene Entscheidung mit Kontext, Alternativen und Konsequenzen.

## Format

Wir folgen dem klassischen ADR-Format von Michael Nygard, leicht angepasst:

- **Status:** Vorgeschlagen / Akzeptiert / Abgelehnt / Überholt
- **Kontext:** Was ist die Ausgangslage?
- **Entscheidungstreiber:** Welche Faktoren beeinflussen die Entscheidung?
- **In Betracht gezogene Alternativen:** Was wurde geprüft?
- **Entscheidung:** Was wurde entschieden?
- **Konsequenzen:** Positive und negative Folgen.
